# 作品简介（V1.0.0 最终版 · 200 字以内）

**作品名称**：金枢
**英文名称**：FinTrust Agent
**版本状态**：✅ **已形成最终交付物**（可提交）

---

**金枢（FinTrust Agent）** 是面向银行业的可信 AI 智能体。用户用自然语言下达指令，Agent 识别意图、抽取参数、生成 DAG，经受控工具执行真实业务。

创新在于**权限判定与模型彻底解耦**：策略引擎按金额与日累计划定绿/黄/红三级权限，写操作至少黄色、须确认或多因子验证，模型无权决定权限。并具备认证、账户隔离、限流、注入防御与哈希链审计。

资金变动均为**本地模拟**，不连接真实银行。
